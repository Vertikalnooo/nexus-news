# Preview security review
No Telegram transport or token access in publisher. HTML escaped; HTTPS canonicalized; preview only. RSS fetch disallows redirects and bounds response bytes; configured source URLs must remain trusted, not user-controlled. XML parser rejects DTD/entity strings but encoding bypass needs testing. Translation output is not fact-verified; review required. Macro drafts lack text renderer and release verification; do not publish. PostgreSQL uses verify-full, atomic reservation and explicit transactions; cloud least-privilege role and migration still pending. Runtime holds connection during model setup; scale-to-zero and actual resource usage unverified. Dependencies and model revision are not pinned to immutable hashes; do not expose production credentials to dependency installation. Scheduler remains disabled. CI smoke uses public data and temporary SQLite only. No production activation until these blockers are addressed.
