 # Audit — OPEN
Deferred constraint triggers recheck expiry at normal COMMIT, but SET CONSTRAINTS IMMEDIATE can force early execution and a privileged or arbitrary SQL client can hold a transaction past expiry. PostgreSQL does not expose an unbypassable SQL precommit hook to this design. Do not claim strict commit deadline; require trusted autocommit gateway, no raw login access and external session termination before live use. Mock transitions are monotonic but finish_mock is not bound to the claiming worker or a real receipt; mock only. Linux parent-death signal protects direct child, not detached descendants; preexec_fn assumes single-threaded supervisor. Full CI pending. No real APIs or cloud migrations.
