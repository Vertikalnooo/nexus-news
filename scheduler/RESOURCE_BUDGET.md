# Preview resource budget
At 24 runs/day and a 10-minute job timeout, a 31-day month allows up to 124 runner hours. This is not a provider billing cap. At 0.25 CU and 10 minutes active per run, theoretical compute is 31 CU-hours; idle time and other connections add usage. Continuous activity could reach 186 CU-hours. Do not activate before checking actual scale-to-zero, storage and usage in Neon console. Free-tier consumption API is unavailable. Keep Gemini disabled. Public standard GitHub runners only; no larger runners or paid services. OPUS downloads before DB reservation in the current template, so the DB budget does not cap runner usage. Keep template disabled until this is addressed.
